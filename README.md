💧 Water Level Alarm Simulator

📌 Project Overview

The Water Level Alarm Simulator is a simple interactive web-based project designed to demonstrate how a water tank monitoring and alarm system works.

It allows users to adjust the water level using a slider and displays the corresponding water level status. When the water level reaches 80% or above, the alarm is activated.

🎯 Objectives

- Understand the working principle of a water level monitoring system.
- Demonstrate basic conditional logic using JavaScript.
- Simulate water level detection.
- Understand how an alarm system responds to different water levels.

⚙️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and user interface.
- JavaScript – Water level detection and alarm logic.

🚀 Features

- Interactive water tank simulation.
- Adjustable water level slider.
- Live water level percentage display.
- Three water level conditions: LOW, MEDIUM, and HIGH.
- Automatic alarm activation at high water levels.
- Reset button to restore the tank to its initial state.
- Responsive user interface.

📊 Working Logic

Water Level| Status| Alarm
0–39%| LOW| OFF
40–79%| MEDIUM| OFF
80–100%| HIGH| ON

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Adjust the slider to change the water level.
5. Observe the status and alarm indicators.
