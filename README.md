💧 Water Level Alarm Simulator

📌 Project Overview

The Water Level Alarm Simulator is a simple interactive web-based project designed to demonstrate how a water tank monitoring and alarm system works.

It allows users to adjust the water level using a slider and displays the corresponding water level status. When the water level reaches 80% or above, the alarm is activated.

🎯 Objectives

- Understand the working principle of a water level monitoring system.
- Demonstrate basic conditional logic using JavaScript.
- Simulate water level detection.
- Understand how an alarm system responds to different water levels.


📊 Working Logic

Water Level| Status| Alarm
0–39%| LOW| OFF
40–79%| MEDIUM| OFF
80–100%| HIGH| ON
